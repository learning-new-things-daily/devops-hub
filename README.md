# DevOps Hub

A static site hosted on GitHub Pages featuring:

- DevOps tutorials and tools
- Blog posts with affiliate marketing
- Premium downloadable scripts via Gumroad
- A contact page for freelance services

## 📦 Structure

- `index.html` - homepage
- `/blog/` - blog posts
- `/scripts/` - downloadable tools
- `contact.html` - form and contact info

## 🚀 Deployment

1. Push to a GitHub repo named `<yourusername>.github.io`
2. Enable Pages from `main` branch
3. Done 🎉

## 💰 Monetization

- Affiliate links in blog
- Gumroad for script downloads
- Formspree + Contact page for leads
